CPIT-405 Portfolio Assignment — Blue Bloom Edition

Files:
- index.html: Home page / introduction / education / skills / CV snapshot
- labs.html: Labs and projects
- contact.html: Contact details and FormSubmit contact form
- style.css: Shared blue, sky, and soft floral-pink styling, responsive layouts

Step-by-step:
1. Extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Replace placeholders such as [Your Full Name], [Your Student ID], and sample email with your own information.
4. In labs.html, keep only labs you actually completed and replace every # / Add link with the real link.
5. Replace sample project names/descriptions with your own real projects.
6. In contact.html, update the visible email and replace YOUR_EMAIL@example.com in the form action with the email that should receive messages.
7. FormSubmit may send a confirmation email the first time. Confirm it, then test the form after publishing.
8. Preview index.html in your browser; check navigation and mobile layout.
9. Upload all files to a GitHub repository, enable GitHub Pages, and copy the live URL.
10. Submit the live link and a ZIP named with your student ID on Blackboard.

Important: lab/project examples are placeholders, not verified completed work. Do not submit inaccurate links or information.
